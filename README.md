# ArchiSpace

### Archit Renjeev's desk, built in code — everything on it is real.

ArchiSpace is the personal site of **Archit Renjeev**, a backend-focused developer and AI & Data Science student in Bengaluru, India. The homepage is an interactive 3D desk: an HP Omen 16 cycling through his real, live websites (CivicEye, ArchiSpace, MetrikAI), a Nothing Phone running AgriPulse with its Glyph back, earbuds, an RGB workbench, and a 3D printer — every project shown is real and built by him.

Below the desk: the work, the toolkit, the story, and how to reach him (GitHub: [Crepify](https://github.com/Crepify)).

## What's here

- **The desk + portfolio** — the Next.js site at the repo root (`src/`, `public/screens/` for real project screenshots).
- **Public calculators** — `/tools`: credit-weighted SGPA/CGPA, attendance, assessments, and target planner. No account needed; inputs never leave the tab. Served from the preserved bundle in `public/legacy/`.
- **Owner workspace** — `/owner`: Archit's private, sign-in-only workspace, unchanged from before.
- **Résumé** — `/resume`.
- **`legacy-vite/`** — the previous Vite implementation of ArchiSpace, preserved in full (including its docs). The live legacy pages under `public/legacy/` are built from it; see `legacy-vite/DEPLOYMENT.md`.

Real projects only — nothing on this site is invented: no fake clients, stats, testimonials, or availability claims.
